# 跨平台文件操作

## 获取实际边界

1. 确定操作针对工作区、技能目录还是用户配置目录。
2. 阅读现有路径解析、授权校验和写队列，不新建平行的绕过路径。
3. 在 dsh-plugins 可参考文件管理插件的 `lib/file-actions.js`、
   `lib/zip.js` 和仓库插件的 `lib/skill-store.js`。

## 路径与名称

- 宿主路径拼接使用 `join/resolve/relative`，不要用字符串前缀代替目录包含判断。
- 判断后代路径时检查 `relative()` 结果是否绝对路径，以及是否等于
  `..` 或以 `..` 加实际分隔符开头。
- 浏览器处理远程路径时不能依赖浏览器运行平台；识别盘符根、UNC、
  POSIX 根与分隔符语义，测试根目录不能被截成 `C:`。
- 区分 URL 路径、归档路径和宿主路径；归档中的 `/` 不等于宿主分隔符。
- 用户文件名校验依目标平台而定；可分发的技能包则需同时满足 Windows
  设备保留名、非法字符、尾点及尾空格规则。
- 检查大小写和 Unicode 归一化冲突；不要假设所有 macOS/Linux 卷都大小写敏感。
- 拒绝路径穿越和不允许的符号链接；`lstat()` 校验不构成消除外部竞态的保证。

## 写入与批量操作

1. 先预检批次内同名冲突及源目标重叠，再进行任何写操作。
2. 合并父子源项，避免对子项重复执行或在父目录移动后引用旧路径。
3. 同工作区写操作串行化，读取失败不得被误当成不存在。
4. 保存使用同目录独立临时路径，完整写入后原子替换，失败清理暂存。
5. 使用读取版本防止覆盖外部修改；权限保留以目标平台能力为准。
6. 移动仅在 `EXDEV` 时考虑复制删除回退；复制成功前不删除源。
7. 批量部分失败时准确报告已完成项；需要整体事务时先设计备份和恢复。

## 归档与验证

- 压缩优先流式处理；读取和解压限制条目数、单文件及总大小。
- 解包前检查 CRC、声明大小、路径重叠、符号链接及特殊文件；
  不调用包内脚本，不信任扩展名。
- 在根 `demo-test/` 覆盖盘符、UNC、POSIX、设备名、并发冲突、
  外部修改、权限、取消、失败清理及大数据限制。
- 明确哪些检查是模拟路径、哪些是本机实测；不能把 Windows 测试
  表述为 macOS/Linux 真机通过。
